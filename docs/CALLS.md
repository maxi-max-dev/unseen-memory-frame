# 三种不同的联系与语音功能

| 入口 | 实际用途 | 未配置时 |
| --- | --- | --- |
| 联系家人 / 站内提醒 | 给家庭成员发站内联系请求，对方可确认收到 | 不需要音频中继；不是电话 |
| 和家人语音通话 | 双方打开页面、主动接听后使用 WebRTC 音频 | 显示未启用或中继配置原因，不申请麦克风 |
| AI 实时语音 | 与配置的 AI 实时服务交谈 | TRTC 等配置不完整时禁用；普通文字聊天仍可用 |

相框展示模式只保留日常听、说和照片操作。退出展示后进入高级功能；家人端也提供通话入口。退出展示不会退出家庭配对。

## 可选家庭通话配置

保持默认 `MEMORY_CALL_ENABLED=0`。确有受控 TURN 中继、带宽与费用安排后，管理员在服务端私有环境配置以下字段，完成两台设备跨网验收才启用：

- `MEMORY_CALL_ENABLED=1`
- `MEMORY_CALL_ICE_SERVERS_JSON`：1～4 项、仅含 `urls` 的数组，至少一个受控 `turn:` 或 `turns:` 地址；不能只提供 STUN，也不能包含静态浏览器用户名/密码。
- `MEMORY_CALL_TURN_SECRET`：32～512 字符的私有共享密钥，服务端按通话签发短时凭据；不可打入前端或提交 Git。

浏览器需要安全上下文、WebRTC 和麦克风支持。双方打开页面并主动接听后才申请麦克风；关闭、切后台、断网或退出会释放本机媒体。挂断未获服务器确认时保留重试，不能当作已彻底结束。前台页面提示不是系统来电推送，没有手机号码拨号能力。

家庭通话与 AI 实时语音不共用配置。公开仓库中的单元/模拟媒体测试以及禁用状态的实际 HTTP 浏览器检查，不等于 TURN、真人声音或扬声器已经验收。
