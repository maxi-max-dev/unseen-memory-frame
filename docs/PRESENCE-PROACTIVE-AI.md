# 驻足确认后：AI 读固定照片并先问一句

驻足事件只触发邀请。邀请会明确说明确认后读取照片并提问，老人选择“和 AI 聊聊”后，受控入口 `MemoryAI.openFromPresence(messageId)` 才检查可用能力并发起最多一次 `aiChat` 首问请求。使用邀请显示时固定的照片，后台收到新照片或相框切换展示不会改变这次确认的对象。

首问只显示 AI 的一句文字问题，不把内部自动提示伪装成老人发言。没有自动朗读、麦克风申请、录音、实时语音或联系操作。朗读需要点击“朗读回复”；普通 `MemoryAI.open()` 与 `MemoryAI.open(messageId)` 仍保持手动行为，不会自行读取图片或调用聊天模型。

## 生成与失败处理

提示要求依据明确可见的细节，提出一句简短、温和、开放式的问题，不猜测人物身份、亲属关系、地点、时间、情绪或照片背景。前端只接受 `imageUsed:true` 且不超过 160 字的单一问句，其余结果回到普通聊天。

能力检查失败、没有读图能力、模型失败、未实际读图或首问格式不合适时，会说明已保留普通对话并取消读图勾选，不自动重试。用户可手动重查能力，重查不会重新自动提问。模型返回的行动建议不会在首问入口生成确认卡片或执行。

提示与格式检查不能保证真实模型始终准确。请在自己的供应商配置、照片与目标设备上验收，不把测试替身的回答作为视觉质量证据。

## 取消与会话隔离

- 能力检查和模型响应绑定原对话对象、打开代际、账号会话、家庭、照片 ID 与图片标识，返回前复核页面可见性、照片和忙碌状态。
- 关闭、停止、清空、切后台、切换实时语音或家人通话暂停会取消首问。状态刷新发现照片删除或替换时立即取消。
- 快速关闭后重开同一照片，旧响应不能触发新的首问或覆盖新草稿。已发出的请求会中止等待并忽略迟到结果；不能承诺撤回供应商已接收的计算。
- 等待期间禁用发送、录音和换图，保留停止与关闭。首问完成后恢复手动对话；API 历史保留完整 user/assistant 配对，隐藏内部种子的展示标记不进入 API。
- 驻足事件的期限、去重、忙碌门禁和撤销策略保持，未接受的事件不排队重试。固定照片不代表识别了老人身份或注视方向。
