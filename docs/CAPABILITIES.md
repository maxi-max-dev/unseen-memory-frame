# 能力与验收边界

| 能力 | 本仓库实现 | 仍需自己的环境验收 |
| --- | --- | --- |
| 家庭、账号、邀请和相框配对 | Node API + 原生页面 + 隔离测试 | 双设备点击、网络恢复与账号管理流程 |
| 照片、文字、原声和回执 | 家人发送、相框播放/回复、历史分页 | 真人手机录音、扬声器与浏览器授权 |
| 相框展示模式 | 简洁照片展示、侧边翻页、可选轮播、听与说、退出后高级入口 | 浏览器全屏支持、实体屏幕与触控；轮播不能取代音频/录音安全检查 |
| AI 文字、照片与录音转写 | 服务端供应商适配、格式约束、确认卡片 | 模型权限、费用、真实照片质量和真人语音 |
| Windows Link 2 驻足邀请 | Windows 采集/上报文本源码、短时状态、前端邀请与确认后固定照片 AI 开场 | 官方 SDK 编译、实体 Link 2、Windows 与平板完整联合运行 |
| 3D 空间记忆 | 安全导入、权限分段、摘要、查看器 | 自有模型、移动 GPU、触控、弱网与长时间稳定性 |
| AI 实时语音 | 默认关闭的 TRTC 接口与清理机制 | TRTC 权益、房间权限、流式模型、真人声音和打断 |
| 和家人语音通话 | 独立 WebRTC 页面与鉴权信令，默认关闭 | 受控 TURN、临时凭据、两台设备主动接听和真实跨网音频 |

接口测试、浏览器替身、真实浏览器页面操作、真人录音和 GPU 渲染分别说明，不能互相替代。Windows 设备端只公开经过审查的文本源码，官方 SDK 与生成二进制不随仓库分发；硬件联调仍待现场完成。这里的主动邀请不代表识别了某个人，也不证明设备具备注视识别能力。老人确认后才进行一次固定照片的 AI 开场，失败可继续普通聊天；不会自动开麦、录音或播放语音。

这是比赛演示项目，尚未提供生产级密码恢复、完整自助数据删除、灾备和容量监控。家庭通话不拨打电话号码，也不是 AI 实时语音；它和站内联系提醒都要求对方打开页面。服务不可用时显示真实原因，不把提醒或已接受信令显示成音频已连通。见 [通话服务边界](CALLS.md)。
