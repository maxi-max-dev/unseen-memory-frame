# 能力与验收边界

| 能力 | 本仓库实现 | 仍需自己的环境验收 |
| --- | --- | --- |
| 家庭、账号、邀请和相框配对 | Node API + 原生页面 + 隔离测试 | 双设备点击、网络恢复与账号管理流程 |
| 照片、文字、原声和回执 | 家人发送、相框播放/回复、历史分页 | 真人手机录音、扬声器与浏览器授权 |
| AI 文字、照片与录音转写 | 服务端供应商适配、格式约束、确认卡片 | 模型权限、费用、真实照片质量和真人语音 |
| Windows Link 2 驻足邀请 | 传感器上报到短时状态、前端邀请 | Windows 采集器、硬件和云端联合运行 |
| 3D 空间记忆 | 安全导入、权限分段、摘要、查看器 | 自有模型、移动 GPU、触控、弱网与长时间稳定性 |
| AI 实时语音 | 默认关闭的 TRTC 接口与清理机制 | TRTC 权益、房间权限、流式模型、真人声音和打断 |

接口测试、浏览器替身、真实浏览器页面操作、真人录音和 GPU 渲染分别说明，不能互相替代。Windows 采集器不在本仓库内；其实现由对接方维护。这里的主动邀请不代表识别了某个人，也不证明设备具备注视识别能力。

这是比赛演示项目，尚未提供生产级密码恢复、完整自助数据删除、灾备和容量监控。家人实时电话不属于本次主流程；站内联系提醒只有对方打开页面后才能看到。
