# unseen 记忆相框：家人和相框怎么用

先按 [README](../README.md) 启动应用或[部署到自己的 HTTPS 环境](DEPLOYMENT.md)。以下 `/family`、`/frame` 都是你自己的服务地址，不提供预置线上账号。手机负责寄照片、文字和原声；老人平板负责观看、收听和回复。

## 进入家庭和配对相框

1. 家庭创建者打开 `/family`，选择“注册账号 → 创建新家庭”，填写账号、密码、家庭名称和部署者提供的开通码。已有账号只需登录，日常登录不用开通码。
2. 创建者在“我的 → 邀请家人 / 配对 → 邀请家人”生成邀请。其他家人在自己的手机打开邀请，填写账号、密码和称呼，注册并加入；不要为了换设备反复创建家庭。
3. 给平板使用“配对相框”邀请，在平板打开并填写相框称呼。也可先打开 `/frame`，粘贴配对链接或邀请码。相框不需要家人账号，两种邀请不能互换。邀请有效 24 小时，失效后重新生成。

## 家人寄出，老人回复

1. 手机点底部中央“＋”，选照片、写一句话，也可以只写文字。演示时可使用仓库内的中性图片 `server/public/assets/demo.png`。
2. 要留原声，点“录一段原声”，允许麦克风，录好后结束并试听，再点“寄到相框”。每段最长 60 秒；非本机设备需要 HTTPS。
3. 平板保持 `/frame` 打开，连接后收到新内容。绿色“听原声”播放家人录音，红色“说一说”录制回复；录好后仍需点击“发送给家人”。
4. 家人在首页查看回信，听原声、修订文字、补人物和年份，再保存修订。AI 整理的内容仍需家人核对。

草稿保存在当前浏览器，发送失败时保留页面并重试。手机的“预览老人相框”只供预览，不会替老人产生观看或听取回执。

## 普通聊天和驻足邀请

“和 AI 聊天”允许输入文字后发送。需要读图时，展开“添加家庭照片”，选择最多 4 张并勾选“让 AI 读取当前选中的照片”。“用语音输入”和“朗读回复”都由用户主动点击。没有配置对应服务时会明确提示；实时语音显示“尚未开通”时可以返回文字聊天。

家庭创建者在“我的 → 设置 → 管理相框驻足邀请”选择目标相框，填写设备标识并签发独立传感器令牌。把自己的 HTTPS `/api` 地址和令牌私下交给 Windows 设备管理员，每台相框分别绑定；轮换令牌后设备端也要更新。详见 [Windows 设备端](../devices/link2-windows/README.md) 和[驻足协议](PRESENCE-CLOUD-API.md)。

驻足只触发邀请。老人确认后，AI 才读取该次邀请固定的照片并温和问一句。首问只显示文字，不自动朗读或打开麦克风；失败可继续普通聊天。见[确认后 AI 开场说明](PRESENCE-PROACTIVE-AI.md)。

## 影石 3D 空间

在影石 App 打开已经生成的时光舱作品，选择分享 → “网页链接分享”。家人点中央“＋ → 3D 空间”，粘贴完整作品链接或含单个链接的分享文字，看到已识别提示后点“寄出并导入空间”。待卡片显示“空间可观看”，家人端和相框端均可打开。

导入失败时查看卡片原因，选择重试或查看影石来源。普通视频不能直接重建为空间；本入口不接收本地 SOG、ZIP 或其他模型文件。未支持的资源域名会被拒绝，不能通过放宽安全检查解决。

## 常见问题与验收边界

- 收不到内容：确认两端属于同一家庭，平板打开的是 `/frame` 且显示已连接；手机预览不表示真实平板在线。
- 不能录音：检查 HTTPS 与浏览器麦克风授权，录好后确认发送。
- 邀请或配对失效：由家人重新生成对应邀请；传感器绑定过期的相框会话后也需更新绑定。
- 忘记密码：当前尚无自助找回或改密码入口，联系自己的部署者处理。
- 本地与云端是独立存储，账号不能互相通用。

接口、浏览器和 provider 替身测试不代表实体 Link 2、真人录音、真实模型质量、iPad 或硬件 GPU 已验收。完整边界见[能力说明](CAPABILITIES.md)。
